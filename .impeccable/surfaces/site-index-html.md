# Surface: difftray.app landing page

Mode: Persuade. Audience: developers who review agent-written changes on a Mac. Action: download the free Mac app (Apple silicon or Intel); secondary: companion from the App Store or Google Play. Proof: real dark-theme captures of the app with agent-attributed comments and a drift flag; real CLI commands and slash commands. Constraints: no invented users, logos, benchmarks or prices; Pro is "free for one project, Pro unlocks every project".

## Direction contract

THESIS: The page is the loop itself: an agent at a terminal and Difftray beside it, reviewing the same diff. It refuses the glow hero, badge pill, gradient word and the uniform feature-card grid.

OWN-WORLD: The app's real dark theme: graphite #151619 / #191a1c ground, #1f2024 panels, #26282b hairlines, text #d1d3da. States are the only colours: reviewed green #73bd79 (primary action), drift amber #d9b64e, agent blue #5da9ff, deletion red #ff7a70. Display Schibsted Grotesk, body IBM Plex Sans (the app's face), JetBrains Mono only for code, commands and the terminal.

STORY: You and your agent review the same diff; the agent reads your comments and writes its own, attributed; a reviewed file that changes again is flagged; you can read it all from your phone. Then download.

FIRST VIEWPORT: A full-width band with the H1 and a three-sentence lede (the third carries the drift beat) on the left and the green "Download for Mac" with "Free · macOS 13 or later" and the Intel link on the right; below it the desk, where a terminal pane overlaps the lower-left edge of a legible crop of the real Difftray diff. Stacked rather than a 40/60 split hero because the Persuade rules name the copy-beside-product split as the template, and the crop needs the width to stay readable; terminal lines run once; when "feedback submit" lands, the matching comment cards in the capture get an outline. "Works with Claude Code, Codex, Pi" sits under the split.

FORM: Pinned by the user from the critique round: "Two terminals, one desk" (direction B); the roll was not used to pick it. seed:24bfc3095edc00b2
